# fc-racks

Демо: конфигуратор стеллажей и их расстановки по зданиям, этажам и рядам.
Только фронтенд, данные хранятся в `localStorage`, при первом открытии загружается демо-склад.

Стек: React + TypeScript + Vite, Tailwind CSS v4 + shadcn/ui, Zustand (`persist` + `immer`),
`@dnd-kit` (drag & drop), `zod` (валидация JSON), `react-router` (`HashRouter`).

## Страницы

| Раздел | Страница | Что делает |
|---|---|---|
| Шаблоны | **Визуально** | Конструктор фасада стеллажа: «+» в полке добавляет ячейку, справа — число ячеек, порядок, копия, удаление полки; пресеты и формула `4-3-2` |
| Шаблоны | **Форма** | Тот же шаблон через таблицу полок + живое превью |
| Расстановка | **План** | Дерево зданий/этажей, план этажа с рядами; стеллажи добавляются «+» или перетаскиванием из палитры, переставляются drag & drop |
| Расстановка | **Мастер** | Массовая генерация: здания → этажи → ряды → состав рядов → итог |
| Расстановка | **Таблица** | Вся расстановка одной таблицей, состав ряда — чипы |
| Результат | **Просмотр** | Здания → этажи → план этажа → фасад ряда с адресами ячеек |
| Результат | **JSON** | Экспорт (копировать/скачать), развёрнутый список ячеек, импорт с проверкой схемы |

## Формат данных

```json
{
  "version": 1,
  "rackTemplates": [
    { "id": "tpl_1", "name": "Тип A", "color": "#3b82f6",
      "shelves": [ { "id": "sh_1", "cells": 4 }, { "id": "sh_2", "cells": 3 }, { "id": "sh_3", "cells": 2 } ] }
  ],
  "buildings": [
    { "id": "bld_1", "name": "Здание 1", "floors": [
      { "id": "fl_1", "name": "Этаж 1", "rows": [
        { "id": "row_1", "name": "Ряд 1", "racks": [ { "id": "rk_1", "templateId": "tpl_1" } ] }
      ] }
    ] }
  ]
}
```

- Полки перечисляются **снизу вверх**, у каждой — своё число ячеек (ячейки делят полку поровну).
- Стеллаж в ряду ссылается на шаблон (`templateId`); порядок в массиве — порядок в ряду слева направо.
- Адрес ячейки вычисляется по позициям: `З1-Э2-Р3-С4-П2-Я1` (здание, этаж, ряд, стеллаж, полка, ячейка).
- Схема — `src/domain/schema.ts`.

## Запуск

```bash
npm install
npm run dev       # http://localhost:5173/fc-racks/
npm run build     # сборка в dist/
npm run preview   # просмотр собранной версии
```

Добавить компонент shadcn: `npx shadcn@latest add <name>`.

## Публикация на GitHub Pages

1. Settings → Pages → Source: **GitHub Actions**.
2. Каждый push в `main` собирает и публикует сайт (`.github/workflows/deploy.yml`):
   `https://<user>.github.io/fc-racks/`

Если репозиторий называется иначе — поменяйте `base` в `vite.config.ts`.
